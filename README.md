# TradeYar Asemun — ترید‌یار آسمون

دستیار هوشمند تحلیل و مانیتورینگ بازار طلا، سکه، انس جهانی، نقره، بیت‌کوین، نفت.

## نصب

pip install -r requirements.txt

## اجرا

streamlit run app.py

## ساختار

- core/ — منطق تحلیل و دریافت داده
- ui/ — کامپوننت‌های رابط کاربری
- data/ — داده‌ها و لاگ سیگنال‌ها
- fonts/ — فونت‌های سفارشی (اختیاری)
